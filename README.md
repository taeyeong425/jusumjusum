## v0.6 보물찾기 — 무엇이 바뀌었나

놀이터 부품 뜯기 → **라운드마다 다른 공간에서 보물찾기.** 찾은 봉투 속 파츠로 조립한다. 라운드 구조(공개 → 수집 → 조립 → 전시 → 정산, 3라운드)는 그대로.

| 라운드 | 공간 | 숨는 곳 | 만들 것 |
|---|---|---|---|
| 1 | 학교 — 교실 둘 · 복도 · 교무실 · 음악실 · 도서관(2층 다락) · 미술실 · 운동장 | 책상 서랍 · 사물함 · 피아노 뚜껑 · 액자 · 책장 칸 | 지구본 · 책가방 · 탁상시계 |
| 2 | 미술관 — 조각 홀(2층 발코니) · 전시실 셋 · 창고(사다리 선반) · 광장 | 액자 뒤 · 받침대 서랍 · 진열장 · 포장 상자 | 조각상 · 이젤 · 꽃병 |
| 3 | 해적선 — 화물칸 · 갑판 · 선장실 · 뒷갑판 · 돛대 망루(밧줄 사다리) | 술통 · 나무 상자 · 보물상자 · 해먹 · 선장 책상 | 닻 · 앵무새 · 보물상자 |

- **보물 = 인원 × 1.5 × 10** (6명 = 90개): 쪽지 60% (파츠 1) · 편지봉투 30% (파츠 2, 대부분 가구 속) · 금봉투 10% (파츠 3, 높은 곳 · 깊은 곳). 먼저 줍는 사람이 임자
- 파츠는 판정 12종 그대로, **이름 · 색 · 변형만 테마별** (해적선: 나무통 · 대포알 · 돛 천 · 닻 고리 …)
- **조립 시작 때 봉투 개봉식** — 눌러서 열기 · Space 하나씩 · A 모두. 이 동안 시간은 안 간다
- 지붕 없는 인형의 집 시점 · **위층 바닥 아래에 있으면 위층이 사라진다** · **캐릭터 앞을 가리는 벽엔 구멍** (셰이더)
- 계단 · 사다리 · 여러 층을 잇는 길찾기 (AStar3D) — 도달 테스트 학교 54/54 · 해적선 36/36
- 보물 감지기 (미니맵 아래 ●●●○ — 가까울수록 차고 똑딱)
- 카드 교체: 황금 손(금봉투) · 뒤지기 장인(가구 속 3) · 높은 곳 탐험가(위층 2) · 싹쓸이(8개) + 만들기 카드
- 에셋: 모서리 깎은 상자 메시 · 바닥 셰이더(나무 판자 · 체크 타일 · 대리석 · 카펫) · 움직이는 바다 · 공용 가구(`scripts/maps/props.gd`)

## 조작

**수집** — 배그(PUBG)식: 시점은 항상 마우스, 고르기는 조준점 / 가방

| 입력 | 동작 |
|---|---|
| 마우스 움직이기 | 시점 돌리기 (웹은 처음에 화면을 한 번 클릭) |
| [F] · 클릭 | 가운데 조준점에 있는 것 → 길을 찾아 걸어가서 줍기 · 뜯기 (원형 게이지 + 움켜쥐는 손) |
| [Tab] | 가방 — 커서가 풀리고 「근처 5m」 목록에서 골라 줍기 (걸으면서도 됨) |
| Esc | 커서 풀기 (「수집 끝내기」 버튼 등) · 다시 화면 클릭하면 시점 조작 |
| WASD · Space | 이동 · 점프 (객차·화물칸·차는 걸어가면 폴짝 올라탄다 · 미끄럼틀은 계단으로). **움직이면서도 손 닿는 거리면 줍기 · 뜯기가 계속된다** |
| 휠 | 줌 |
| 1~0 | 핫바 칸 고르기 (15칸) |
| [Q] | 고른 칸 버리기 (지나가도 자동으로 안 주워진다) |

편의 보정: **길찾기(A*) — 건물 · 울타리를 돌아서 간다 (클릭 도달률 70% → 100%)** · 가속/감속 · 코요테 타임 0.12초 · 점프 버퍼 0.15초 · 조준점 48px 관용 · 움직이는 차 · 기차는 3.6m에서 잡기 (차체 · 기관차 몸통도 뜯을 수 있다) · 무릎 높이 턱 자동 오르기 · 남은 30·10·5초 경고음 · 착지 · 줍기 찌그러짐

**조립** (v0.5)

| 입력 | 동작 |
|---|---|

### 덩어리 변형

같은 종류도 비율이 다른 버전이 처음부터 있다. v0.5부터 조립에서 **축별로 늘여 비율도 바꿀 수 있다.**
납작한 원기둥이 필요하면 차 바퀴(「바퀴」)를, 긴 원기둥이 필요하면 가로등(「기둥」)을 뜯어 와야 한다.

| 종류 | 변형 |
|---|---|
| 원기둥 | 원기둥 · 바퀴 · 기둥 · 동전 · **육각기둥 · 삼각기둥 · 화분** |
| 구 | 공 · 럭비공 · 접시 · **보석** · 알 |
| 링 | 링 · 타이어 · 가는 링 · **네모 링 · 반달 아치** |
| 판 | 판 · 넓은 판 · 좁은 판 · 긴 판 · **둥근 판 · 별 판 · 하트 판** |
| 육면체 | 정육면체 · 벽돌 · 기둥 블록 · **ㄴ자 · 계단 · 십자 블록** |
| 막대 | 막대 · 짧은 · 긴 · **ㄱ자 · T자** |
| 원뿔 · 반구 · 캡슐 · 쐐기 · 감자 | **피라미드 · 오각뿔 · 버섯 갓 · 콩 · 지붕 · 울퉁 감자** 등 |

굵은 글씨는 생김새 자체가 다른 변형 (같은 종류로 판정되지만 메시가 다르다). 12종 × 2~7개, `scripts/data.gd` VARIANTS

| 개인 목표 카드 7종 · 티켓 (+30초 / 할당량 한 단계 낮추기) · 부문상 8종 | |
| ★5 1인 1개 제한 · 동점 규칙 | |

### 검수 반영

- 할당량 ★ 상한 **4.0** — ★5 1인 1개 제한 하에서 ★4.5 기준은 수학적으로 도달 불가였다
- 기본 선반 = **육면체만** 1인당 5개 보장 — "직선 기근"과 "항상 넉넉"의 충돌 해소
- 동점 규칙 — 상위 절반 = 나보다 *엄격히 높은* 작품이 절반 미만 / 꼴찌만 아니면 = 나보다 *엄격히 낮은* 작품이 하나라도 있음

### 봇 평가에 대해

봇은 작품을 타겟 템플릿과 비교해 "얼마나 닮았나"를 근사한다 (`scripts/judge.gd`).
같은 타겟 고품질 ≈ 0.70~0.90 / 다른 타겟으로 만든 것 ≈ 0.37~0.58 / 무작위 더미 ≈ 0.28~0.39.
사람의 감상을 대신하는 장치라 **틀릴 수 있다**. 실제 게임은 사람끼리 평가한다.

### 할당량 곡선 시뮬레이션 (R7)

`tests/test_balance.gd` — 300판 × 사람 실력 4단계

| 사람 실력 | 평균 도달 라운드 |
|---|---|
| 0.40 | 4.23 |
| 0.60 | 4.49 |
| 0.75 | 4.42 |
| 0.90 | 4.67 |

v0.3부터 실제 판은 **무조건 3라운드**(통과 수와 등수로 결과). 이 시뮬레이션은 할당량 곡선 난이도 확인용으로 "연속 통과 라운드"를 잰다.

봇도 사람과 같은 규칙(모양 고정 · 크기와 회전만)으로 만든다.

기획서 목표 밴드(평균 4~6)의 하단.

## 개발

```bash
# 에디터로 열기
godot -e project.godot

# 자동 플레이 테스트 (전 페이즈를 봇으로 3라운드)
godot --headless -- --autotest
# 보물찾기 (v0.6): 공간 지정 · 도달 테스트 · 길 연결 확인 · 둘러보기 · 개봉식
.tools/godot.sh 300 --headless -- --scenario=reach --theme=ship     # school · museum · ship
.tools/godot.sh 300 --headless -- --scenario=navdbg --theme=museum
.tools/godot.sh 120 -- --scenario=look --theme=school
.tools/godot.sh 120 -- --scenario=ceremony --theme=ship
# 시나리오 테스트: 올라타기 · 미끄럼틀 · 조립 맞춤 · 클릭 도달(reach) · 손 연출 · 가방(창 모드)
.tools/godot.sh 60 --headless -- --scenario=ride   # slide · build · reach · hand · bag

# 판정·밸런스 테스트
godot --headless -s res://tests/test_judge.gd
godot --headless -s res://tests/test_balance.gd

# 웹 빌드 (custom_template 경로에 web_nothreads 템플릿 필요)
godot --headless --export-release "Web" build/web/index.html
node .tools/serve.js   # → http://localhost:8060
```

`main` 브랜치에 푸시하면 GitHub Actions가 웹 빌드를 만들어 GitHub Pages로 배포한다.
