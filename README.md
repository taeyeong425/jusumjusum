# 주섬주섬 (가제) — 프로토타입 v0.2

> 놀이터를 뜯어 덩어리를 모으고, 정해진 물건을 만들어, 다 같이 할당량을 넘기는 창작 파티게임.

Godot 4.7 · 웹(HTML5) 빌드 · 플레이어 1명 + 봇 5명

## 한 라운드

| 페이즈 | 시간 | 하는 일 |
|---|---|---|
| 공개 | 0:20 | 타겟(만들 물건) · 이번 판 재료 편성 · 할당량 · 내 비밀 카드 |
| 수집 | 2:00 | 3인칭으로 놀이터를 돌아다니며 **조준해서 줍기**. 차·기차·집·선풍기·자전거를 **[E] 꾹** 눌러 뜯기, 모래밭 파기. 주운 건 바로 핫바로 |
| 조립 | 3:30 | 작업대에서 덩어리를 옮기고 **크기 · 회전 손잡이**로 다듬어 타겟을 만든다 |
| 전시·평가 | 작품당 10초 | 익명 작품이 한 바퀴 돈다. ★1~5 (★5는 한 번만) |
| 정산 | — | ★ 기준선을 넘은 사람이 할당량만큼 있으면 다 같이 다음 라운드. 못 넘으면 끝 |

## 조작

**수집** — 3인칭 어깨 시점

| 입력 | 동작 |
|---|---|
| 화면 클릭 | 마우스로 둘러보기 시작 (Esc로 풀기) |
| WASD · 마우스 · Space | 이동 · 시점 · 점프 |
| [E] 또는 좌클릭 | 조준점에 걸린 덩어리 줍기 |
| [E] 꾹 | 조준한 부품 뜯기 · 모래 파기 |
| 휠 · 1~0 | 핫바 칸 고르기 |
| [Q] | 고른 칸 버리기 (지나가도 자동으로 안 주워진다) |

**조립** — 축 없는 직접 조작

| 입력 | 동작 |
|---|---|
| 덩어리 끌기 | 표면을 따라 옮기기 (부드럽게 따라온다) |
| 「크기」 손잡이 끌기 | 전체 크기 |
| 「회전」 손잡이 끌기 | 끄는 방향으로 자유 회전 |
| 빈 곳 끌기 · 우클릭 끌기 · 휠 · 가운데 버튼 | 시점 회전 · 줌 · 이동 |
| Q / E · T | 45° 돌리기 · 똑바로 |
| 1~0 | 색 |
| X / Ctrl+D | 거울 복제 / 복제 |
| Del · Ctrl+Z · Ctrl+Y · F | 내리기 · 되돌리기 · 다시 · 시점 이동 |

### 덩어리 변형

같은 종류도 비율이 다른 버전이 처음부터 있다. 조립에서는 **전체 크기와 회전만** 바꾼다.
납작한 원기둥이 필요하면 차 바퀴(「바퀴」)를, 긴 원기둥이 필요하면 가로등(「기둥」)을 뜯어 와야 한다.

| 종류 | 변형 |
|---|---|
| 원기둥 | 원기둥 · 바퀴 · 기둥 · 동전 |
| 구 | 공 · 럭비공 · 접시 |
| 링 | 링 · 타이어 · 가는 링 |
| 판 | 판 · 넓은 판 · 좁은 판 · 긴 판 |
| 육면체 | 정육면체 · 벽돌 · 기둥 블록 |
| … | (12종 × 2~4개, `scripts/data.gd` VARIANTS) |

불규칙한 울타리 안에 모래밭 · 그네 · 시소 · 미끄럼틀 · 놀이집, 도로를 도는 **차 3대**, 레일을 도는 **기차**(역에서 7초 정차),
집 2채 · 선풍기 · 가로등 · 우체통 · 쓰레기통 · 분수 · 아이스크림 수레 · 풍선 · 자전거 · 벤치 · 고깔 · 사과나무 · 기차역.
**전부 같은 덩어리 12종으로 지었다** — 뜯은 모양 · 색 그대로 핫바에 들어오고 작업대에 올라간다.
편성에 비례해 부품이 녹슬어 안 빠진다 (곡면 기근이면 둥근 부품 대부분이 녹슨다).

### 검수 반영

- 할당량 ★ 상한 **4.0** — ★5 1인 1개 제한 하에서 ★4.5 기준은 수학적으로 도달 불가였다
- 기본 선반 = **육면체만** 1인당 5개 보장 — "직선 기근"과 "항상 넉넉"의 충돌 해소
- 동점 규칙 — 상위 절반 = 나보다 *엄격히 높은* 작품이 절반 미만 / 꼴찌만 아니면 = 나보다 *엄격히 낮은* 작품이 하나라도 있음

### 봇 평가에 대해

봇은 작품을 타겟 템플릿과 비교해 "얼마나 닮았나"를 근사한다 (`scripts/judge.gd`).
같은 타겟 고품질 ≈ 0.70~0.90 / 다른 타겟으로 만든 것 ≈ 0.37~0.58 / 무작위 더미 ≈ 0.28~0.39.
사람의 감상을 대신하는 장치라 **틀릴 수 있다**. 실제 게임은 사람끼리 평가한다.

## 개발

```bash
# 에디터로 열기
godot -e project.godot

# 자동 플레이 테스트 (전 페이즈를 봇으로 3라운드)
godot --headless -- --autotest

# 판정·밸런스 테스트
godot --headless -s res://tests/test_judge.gd
godot --headless -s res://tests/test_balance.gd

# 웹 빌드 (custom_template 경로에 web_nothreads 템플릿 필요)
godot --headless --export-release "Web" build/web/index.html
node .tools/serve.js   # → http://localhost:8060
```

`main` 브랜치에 푸시하면 GitHub Actions가 웹 빌드를 만들어 GitHub Pages로 배포한다.
