# 주섬주섬 (가제) — 프로토타입 v0.1

> 놀이터를 뜯어 덩어리를 모으고, 정해진 물건을 만들어, 다 같이 할당량을 넘기는 창작 파티게임.

Godot 4.7 · 웹(HTML5) 빌드 · 플레이어 1명 + 봇 5명

## 한 라운드

|---|---|---|
| 공개 | 0:20 | 타겟(만들 물건) · 이번 판 재료 편성 · 할당량 · 내 비밀 카드 |
| 수집 | 2:00 | 놀이터를 돌아다니며 줍기. 차·집·선풍기·그네를 **[E] 꾹** 눌러 뜯기, 모래밭 파기 |
| 조립 | 3:30 | 작업대에서 덩어리를 배치 · 회전 · **축별로 늘리고 눌러서** 타겟을 만든다 |
| 전시·평가 | 작품당 10초 | 익명 작품이 한 바퀴 돈다. ★1~5 (★5는 한 번만) |
| 정산 | — | ★ 기준선을 넘은 사람이 할당량만큼 있으면 다 같이 다음 라운드. 못 넘으면 끝 |

## 조작

**수집** — WASD 이동 · 우클릭 드래그 시점 · [E] 꾹 뜯기/파기 · [Q] 내려놓기 · 작업대 근처에 가면 자동 보관

**조립** — 블렌더·유니티 씬뷰 표준

| 입력 | 동작 |
|---|---|
| 좌클릭 / 끌기 | 선택 / 표면에 붙여서 이동 |
| 축 핸들 끌기 | 축별 이동 · 회전 · 크기 |
| W · E · R | 이동 · 회전 · 크기 모드 |
| 우클릭 · 휠 · 가운데 버튼 | 카메라 회전 · 줌 · 이동 |
| 1~0 | 색 |
| X / Ctrl+D | 거울 복제 / 복제 |
| Del · Ctrl+Z · Ctrl+Y | 내리기 · 되돌리기 · 다시 |
| Space 꾹 | 전시처럼 돌려보기 |

### 검수 반영

- 할당량 ★ 상한 **4.0** — ★5 1인 1개 제한 하에서 ★4.5 기준은 수학적으로 도달 불가였다
- 기본 선반 = **육면체만** 1인당 5개 보장 — "직선 기근"과 "항상 넉넉"의 충돌 해소
- 동점 규칙 — 상위 절반 = 나보다 *엄격히 높은* 작품이 절반 미만 / 꼴찌만 아니면 = 나보다 *엄격히 낮은* 작품이 하나라도 있음

### 봇 평가에 대해

봇은 작품을 타겟 템플릿과 비교해 "얼마나 닮았나"를 근사한다 (`scripts/judge.gd`).
같은 타겟 고품질 ≈ 0.70~0.90 / 다른 타겟으로 만든 것 ≈ 0.37~0.58 / 무작위 더미 ≈ 0.28~0.39.
사람의 감상을 대신하는 장치라 **틀릴 수 있다**. 실제 게임은 사람끼리 평가한다.

## 개발

```bash
# 에디터로 열기
godot -e project.godot

# 자동 플레이 테스트 (전 페이즈를 봇으로 3라운드)
godot --headless -- --autotest

# 판정·밸런스 테스트
godot --headless -s res://tests/test_judge.gd
godot --headless -s res://tests/test_balance.gd

# 웹 빌드 (custom_template 경로에 web_nothreads 템플릿 필요)
godot --headless --export-release "Web" build/web/index.html
node .tools/serve.js   # → http://localhost:8060
```

`main` 브랜치에 푸시하면 GitHub Actions가 웹 빌드를 만들어 GitHub Pages로 배포한다.

## 구조

```
scripts/
  data.gd         덩어리 12종 · 팔레트 · 타겟 템플릿 8종 · 편성 · 할당량 · 카드
  judge.gd        작품 인식 · 봇 평가 · ★5 제한 · 할당량 판정 · 카드 · 부문상
  bot_builder.gd  봇 작품 (템플릿을 가진 재료로 대체해서 만든다)
  piece.gd        덩어리 노드 (비균등 배율 · 충돌은 배율을 구워서)
  gizmo.gd        런타임 변환 기즈모 (화면 좌표로 핸들 집기)
  game.gd         전역 상태 (autoload)
  phases/         menu · reveal · collect · build · exhibit · settle · gallery
tests/            판정 보정 · 밸런스 시뮬레이션 · 글리프 확인 · 테마 굽기
```
